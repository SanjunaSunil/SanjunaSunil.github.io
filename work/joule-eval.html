The Problem

Evaluating AI agents by hand took over two hours

SAP Joule is an AI assistant embedded across SAP products. As the User Assistance team began testing Joule's responses, quality reviews were done manually — a reviewer would read through a conversation, cross-reference a set of internal guidelines, and write up findings in a document.

With 24 quality guidelines covering grounding, tone, task completion, format compliance, and escalation accuracy, a single evaluation session took more than two hours. There was no structured way to surface quoted evidence, assign severity, or produce consistent improvement recommendations across reviewers.

As Joule expanded to more agents and modules, the manual approach couldn't scale. The team needed a repeatable, structured evaluation workflow.

The Process

Structured criteria, automated scoring, actionable output

I designed and built the evaluation system in three layers:

  • Evaluation criteria: Translated 24 internal User Assistance quality guidelines into structured scoring rubrics — each with a definition, scoring scale (1–5), evidence requirements, and severity classification.
  • LLM-as-a-Judge tool: Built the evaluation platform on SAP AI Core using Claude Code. The tool takes a Joule conversation as input, scores it against all 24 criteria, surfaces quoted evidence from the transcript, assigns a severity level per finding, generates an ideal response, and outputs actionable improvement recommendations.
  • Conversation capture extension: Built a browser extension to capture complete Joule test conversations from the testing interface and transfer them into the evaluation workflow — eliminating manual copy-paste and formatting errors.
  • Adoption and rollout: Ran working sessions with the User Assistance and UX teams to introduce the tool, demonstrated on real conversations, and iterated on the output format based on feedback from reviewers.
The Outcome

Faster evaluations, consistent quality, team-wide adoption

2h → 1h Evaluation time cut by approximately 50% — reviewers spend less time cross-referencing guidelines and more time acting on findings.
120 Test conversations evaluated across 10 Joule agents using the structured workflow.
~30 Colleagues across User Assistance and UX teams adopted the evaluation workflow, establishing a repeatable standard for assessing AI response quality.
