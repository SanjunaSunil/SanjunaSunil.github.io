The Problem

Customers kept hitting the same walls

SAP SuccessFactors Report Center was generating a steady stream of support cases. The existing help documentation was largely conceptual and reference-oriented — it explained what Report Center was, but didn't walk users through the tasks that were actually causing them problems.

Customers contacting support were often stuck on the same small set of issues: permission errors, missing data, report configuration steps that weren't documented end-to-end. Each case took time from support agents and frustrated users who expected to find answers in the help content.

Without analysing the cases, it was impossible to know which documentation gaps were driving the most volume — and without that, any content updates were guesswork.

The Process

Research first, then targeted redesign

  • Case analysis: Reviewed 500 customer support cases filed against Report Center in Jira. Coded each case by error type, the task the user was trying to complete, and the documentation state at the time (existed but incomplete, entirely missing, or present but conceptual only).
  • Pattern identification: Grouped cases into four recurring failure patterns: missing task steps, no troubleshooting path, outdated screenshots, and concept-only content with no procedures. Together these accounted for the vast majority of case volume.
  • Content redesign: Rewrote the highest-impact topics as task-oriented procedures — numbered steps, specific field names, and expected outcomes at each step. Added prerequisite sections to surface permission and configuration requirements before users started a task.
  • Interactive flowcharts: For the most complex troubleshooting scenarios (permission errors, data access issues), built decision-tree flowcharts in Lucidchart and embedded them in the help content — giving users a visual path to resolution without calling support.
  • DITA and CCMS: Authored all new content in DITA using IxiaSoft CCMS, structured for reuse across the Report Center and related reporting topics.
The Outcome

Fewer support calls, better self-service

10% Reduction in customer support cases associated with Report Center in the three months following the October 2025 release — users resolving issues through help content instead of contacting support.
500 Support cases systematically coded and analysed to identify root causes — turning anecdotal feedback into a structured content gap analysis.
Task-first Shifted documentation from concept-heavy reference content to task-oriented procedures and troubleshooting flowcharts aligned to real user failure points.
